Automated Feeding System
Three Feeding Modes:
  • Automated Environment + ML Triggered
    Drought, poor grass, inactive goats
  • Scheduled Time-Based Routine
    Backup feeding schedules
  • Manual User Override
    Emergency or testing
Automated Triggers:
  • 🌡️ High temperature + low humidity (drought)
  • 💧 Low soil moisture
  • 🌱 Poor grass health (computer vision)
  • 🐐 Reduced grazing behavior (ML)
  • 😴 Inactive goats during feeding hours (ML)

Quick Start Guide
1. Add Goats to Inventory

Go to Goat Inventory and add your goats with ID, name, breed, and images.

2. Configure Feeder Device

Create a feeder device in IoT Devices with device_type = "feeder".

3. Add Environmental Data (Testing)

Create sensor readings in Sensor Readings:

Temperature: 34°C (drought condition)
Humidity: 35%
Soil Moisture: 20%
4. Add Grass Health Log (Testing)

Create grass health data in Grass Health:

Greenness Index: 0.25 (poor grass)
Health Status: "poor"
5. Test Automated Feeding

Run the decision engine to check if feeding should trigger:

python manage.py shell
>>> from feeding.automated_feeding import run_automated_feeding_check
>>> run_automated_feeding_check()
6. View Results

Check Automated Feeding Dashboard to see triggers and feeding history!
